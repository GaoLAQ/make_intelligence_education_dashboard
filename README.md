# Make Intelligence Education Dashboard

This project is a GCSE mathematics dashboard built with Next.js, TypeScript, Tailwind CSS, and React Query. It showcases an interactive interface for tracking student performance, topic mastery, and assessment history.

## Getting started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Start the production server:

```bash
npm start
```

## Technologies

- [Next.js](https://nextjs.org/)
- [React Query](https://tanstack.com/query/latest)
- [Tailwind CSS](https://tailwindcss.com/)
- [TypeScript](https://www.typescriptlang.org/)
